GitHub Pages site for **Learn Dutch: Speak NL** (iOS `com.nb.learndutch.app`, Android `com.nb.learndutch`). It lives in the
`learn-dutch/` folder of the `learn-bulgarian-privacy` repository.

The app reads these URLs from `src/constants/legal.ts`. Keep the facts here in sync with the app: storage keys,
energy limits, ad consent, the speech service and the subscription plans.
